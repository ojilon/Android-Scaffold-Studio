# Concepts Documentation

The concept images in `docs/concepts/` provide inspiration for the UI phase. However, the model and validator come first in Phase 1.

## Key Differences from Concepts
- **Concepts show:** Kotlin file names and Fragments, and a ConstraintLayout-style constraint editor.
- **v1 Implementation:** Java + XML, Activities only, LinearLayout-style `column`/`row` containers. Constraint layout is a later phase.
- **Template Count:** The "24 templates" count in concepts is fictional. Real template count starts at a handful.

## Image Reference
- `android-scaffold-studio-main-window.png`: main window (screens-and-states tree, phone-shaped canvas, properties and constraints panel, live device log whose crashes link back to the widget that caused them)
- `android-scaffold-studio-code-split.png`: split Design/Code view (selected widget highlights its XML lines)
- `android-scaffold-studio-template-library.png`: Template library (sidebar navigation, screen states, button styles, JNI bridge)
